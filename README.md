# 금치 프리미엄 스위칭 전략

KRX 국내 금현물과 국제 금시세의 괴리(금치 프리미엄)를 이용해
두 ETF 사이를 오가는 전략의 백테스트 코드와 일일 알림 봇.

---

## 전략

```
평소:  ACE KRX금현물 (411060) 보유
프리미엄 ≥ 5%  →  다음 거래일에 KODEX 금액티브 (0064K0) 로 교체
프리미엄 ≤ 1%  →  다음 거래일에 ACE 로 복귀
```

프리미엄 = `KRX 금현물 종가 ÷ 국제금 원화환산 종가 - 1`

두 ETF 모두 환노출이라 원/달러 요인이 상쇄되고, 프리미엄 변동만 남는다.
연금저축 계좌에서 운용하면 전환 시마다 과세되지 않는다.

### 왜 절대 5%인가

원래 스펙은 20일 볼린저 밴드(μ + 2.9σ)를 썼으나 백테스트에서 매수후보유에 졌다.
프리미엄이 잔잔한 구간에서 σ가 0.1%p대로 붕괴해 문턱이 0.4%까지 내려갔고,
경제적으로 무의미한 움직임에 반복해서 반응했기 때문이다.
절대 임계값은 이 실패 모드를 원천 차단한다.

| 방식 | 2년 총수익 | 전환 |
|---|---|---|
| 매수후보유 ACE | +87.30% | — |
| 볼린저 (μ+2.9σ) | +76.88% | 14회 |
| **절대 5% / 1%** | **+155.73%** | 8회 |

임계값 조합 49개 전부가 매수후보유를 초과했다. 좁은 최적점이 아니라 고원.

### 실제 발동 이력 (2024-08 ~ 2026-08)

| 매수일 | 매도일 | 진입 프리 | 청산 프리 | 상대수익 |
|---|---|---|---|---|
| 2024-10-25 | 2024-11-08 | 5.27% | 1.20% | +4.71%p |
| 2025-02-06 | 2025-03-18 | 9.38% | 1.17% | +10.62%p |
| 2025-09-19 | 2025-10-28 | 2.84% | 0.07% | +4.42%p |
| 2026-02-02 | 2026-02-10 | 7.81% | 0.44% | +2.36%p |

4전 4승. 네 번 모두 진입 후 프리미엄이 1% 이하로 수렴했다.

## 한계 — 반드시 읽을 것

- **표본이 4개뿐이다.** 통계적 검증이 아니라 관찰 수준이다.
  최대 트레이드 하나가 전체 알파의 48%를 차지한다.
- **체결 지연에 취약하다.** 신호 다음 거래일 실행이 +155.73%,
  하루 더 밀리면 +126.24%. 수렴 초기 며칠에 알파가 집중된다.
- **2026년 3월 이후 신호가 없다.** 금값 하락으로 프리미엄이 마이너스 상태.
  프리미엄 3% 이상이던 57일은 100% 금값 상승기였다.
  금값이 오르지 않으면 이 전략은 발동하지 않는다.
- **2026-04-18 KRX 금시장 개방 효과는 미검증.** 해외 LBMA 인증 생산업체 참여가
  허용됐으나, 개방 후 줄곧 하락장이라 공급 개선 효과를 측정할 수 없었다.
  다음 금값 상승기가 첫 시험대다.
- **차익거래가 아니다.** 국내 다리를 공매도할 수단이 없으므로
  프리미엄 평균회귀에 대한 방향성 베팅이다. 손실 가능성이 있다.

투자 자문이 아니다. 실제 운용 전 본인 판단으로 검증할 것.

## 알림 봇 설정

### 1. 텔레그램 봇 생성

`@BotFather` → `/newbot` → 토큰 발급.
생성된 봇과 대화방을 열고 아무 메시지나 하나 보낸다.

### 2. chat_id 확인

```
https://api.telegram.org/bot<토큰>/getUpdates
```

응답의 `"chat":{"id":123456789` 숫자가 chat_id.

### 3. KRX bld 값 확인

data.krx.co.kr 접속 → F12 → Network → Fetch/XHR 필터 → 조회 버튼 클릭
→ `getJsonData.cmd` 요청 → Payload 탭에서 `bld`, `isuCd` 복사.

두 화면에서 각각 수행한다.

- 통계 → 일반상품 → 금 → **개별종목 시세 추이** (종목: 금 99.99_1Kg)
- 통계 → 일반상품 → 금 → **국제금시세 동향**

bld 값은 KRX가 개편할 때마다 바뀐다. 알림이 끊기면 이 절차로 다시 확인한다.

### 4. GitHub Secrets 등록

Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather 토큰 |
| `TELEGRAM_CHAT_ID` | 위에서 확인한 숫자 |
| `KRX_BLD_DOM` | 개별종목 시세 추이 bld |
| `KRX_BLD_INTL` | 국제금시세 동향 bld |
| `KRX_ISU_CD` | 금 99.99_1Kg 종목코드 |

### 5. 테스트

Actions 탭 → `gold-premium-alert` → `Run workflow`.
텔레그램 메시지가 오면 성공.

## 알림 동작

평일 **05:40 KST** 발송 (cron은 UTC 기준 `40 20 * * 0-4`).
장 시작 전에 전 거래일 종가 기준 프리미엄을 받는다.

신호가 없는 날에도 매일 보낸다. 조용하면 봇이 죽은 것인지 신호가 없는 것인지
구분할 수 없기 때문이다.

| 프리미엄 | 표시 | 행동 |
|---|---|---|
| ≥ 5% | 🚨 전환 신호 | 다음 거래일 KODEX 금액티브로 교체 |
| ≥ 3% | ⚠️ 관찰 | 1~2일 내 5% 돌파 가능. 계좌 확인 |
| 1~3% | · 중립 | 유지 |
| ≤ 1% | ✅ 평상 | 국제금 보유 중이면 ACE로 복귀 |

3% 관찰 단계의 리드타임은 실측 **1~2일**에 불과하다.
2년간 3% 경보 14회 중 10회가 실제 5%에 도달했다.

## 백테스트 실행

```bash
pip install -r requirements.txt

# KRX에서 받은 CSV 2개를 병합
python merge_krx_csv.py 금현물.csv 국제금.csv --inspect
python merge_krx_csv.py 금현물.csv 국제금.csv --krx-col 종가 --intl-col 원/g_종가

# 백테스트
python gold_premium_backtest.py data.csv --x 5 --y 1
python gold_premium_backtest.py data.csv --split 2026-04-18
```

인자 없이 실행하면 임계값 그리드 서치가 돌아간다.
`이웃평균CAGR` 컬럼이 과최적화 여부를 판단하는 지표다.
좁은 봉우리 하나만 튀면 신뢰할 수 없다.

## 알려진 문제

**GitHub Actions 러너는 해외 IP다.** KRX가 차단할 가능성이 있다.
차단되면 봇이 오류 내용을 텔레그램으로 보낸다. 대안:

- 본인 PC에서 윈도우 작업 스케줄러로 `python alert.py` 실행
- 국내 리전 클라우드(예: 오라클 클라우드 서울)에 cron 등록

**스케줄 워크플로는 부하에 따라 수십 분 밀린다.** 정시 실행을 기대하지 말 것.

**60일간 커밋이 없으면 GitHub이 schedule을 자동 비활성화한다.**
`keepalive.yml`이 매달 1일과 15일에 빈 커밋을 남겨 이를 방지한다.

**리포는 private으로 둘 것.** KRX 데이터의 저작권은 제공처에 있다.
